  의료자문(자문의)이 개입한 거절에 대해 환자가 쓸 수 있는 절차적 대응 레버를 단계별로
  제공한다. 사용 시점: 거절에 의료자문이 개입했을 때(medical-advisory-responder).
---

### 기능 설명
동의 전/후로 나눠 적용 가능한 레버를 선별: 자문 단독 거절 불가 원칙, 동의 거부권,
주치의 소견 선제출, 자문의 선정 이의, 중립 제3자 자문·재감정 요구.

### 입력 형식
{ 단계:"동의 전|동의 후", 거절상태:"심사 중단|일부지급|부지급" }

### 출력 형식
{ 적용레버[순서], 주의 }

### 사용 예제
**예제 1: 동의 전, 심사 중단 압박**
- 입력: { 단계:"동의 전", 거절상태:"심사 중단" }
- 출력: 레버=[자문 의뢰 사유 확인 → 주치의 소견서 선제출 → 동의 신중 결정], 주의=무기한 중단의 부당성 기록

**예제 2: 동의 후, 부지급**
- 입력: { 단계:"동의 후", 거절상태:"부지급" }
- 출력: 레버=[자문의 선정·익명·비용부담 이의 → 합의된 제3 의사 재감정 요구 → 분쟁조정 신청]
