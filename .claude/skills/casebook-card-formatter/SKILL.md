  표준 사례집 카드(요지 중심)와 이의신청 초안 골격을 일관된 양식으로 출력한다.
  사용 시점: 모든 분석 종합 단계(casebook-card-writer).
---

### 기능 설명
판정에 따라 칸 구성을 분기(다툼가능=반박 칸 / 정당 면책=수용 안내 칸).

### 입력 형식
{ 판정, 질환, 거절사유, 반박요지, 의료자문대응, 진료의증빙 }

### 출력 형식(표준 카드)

```
[질환·시술] / [실손 세대]
1) 주요 거절 사유
2) 판정: 다툼가능 / 정당(수용) / 위험
3) 핵심 반박 요지(약관·판례·조정례)      ※정당이면 생략
4) 의료자문 대응 요지                     ※해당 시
5) 진료의 증빙 요지(객관적 기록 중심)
6) 환자 행동 단계(1·2·3)
7) 이의신청 초안 골격(빈칸 포함)
8) 마음 정리 / 정당 거절 수용 안내
9) 면책 고지(참고용 초안·전문가 확인 권장)
```

### 사용 예제
**예제 1: 다툼가능(백내장 입원)**
- 출력: 3)~7) 채움, 8) 절차 안내 중심

**예제 2: 정당 면책(영양주사)**
- 출력: 3)~4) 생략, 8) "치료목적 비해당—이렇게 이해·수용" 안내 중심
