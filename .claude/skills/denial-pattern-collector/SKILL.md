name: denial-pattern-collector
description: |
  특정 질환·시술의 지급거절 사유 패턴을 분쟁조정례·판례·소비자원·언론 자료에서 수집해
  유형·근거·빈도·평균 미지급 규모로 구조화한다.
  사용 시점: 새 질환 카드를 조사할 때(denial-case-researcher).
---

### 기능 설명
거절 사유를 의학적/절차적/면책으로 분류하고 세대별 차이를 메모.

### 입력 형식
{ 질환: "도수치료", 세대: "2세대", 추가맥락: "57회 중 9회분 거절" }

### 출력 형식
{ 패턴:[{유형, 설명, 근거, 빈도}], 세대유의점, 평균미지급(있으면), 출처메모 }

### 사용 예제
**예제 1: 백내장 다초점렌즈**
- 입력: { 질환:"백내장 다초점렌즈" }
- 출력: 패턴=[입원 불인정(통원 한도 적용), 수술 필요성 불인정], 세대유의점=세대별 통원한도 상이

**예제 2: 도수치료**
- 입력: { 질환:"도수치료", 세대:"2세대" }
- 출력: 패턴=[횟수 초과, 치료효과·인과관계, 의료자문 개입], 비고=5세대는 비중증 비급여 제외
