name: physician-evidence-kit
description: |
  쟁점별로 필요한 진료의의 객관적 기록을 증거력 순으로 목록화하고, 의사에게 정중히
  요청하는 문안을 생성한다. 사용 시점: 증빙 보강 단계(treating-physician-evidence).
---

### 기능 설명
진료기록·검사결과지·치료기록지·영상·소견서를 쟁점에 매핑하고 확보 방법을 안내.

### 입력 형식
{ 쟁점:"입원 실질" | "치료 필요성" | "인과관계" }

### 출력 형식
{ 필요서류[증거력 순], 확보방법, 소견요청 문안초안 }

### 사용 예제
**예제 1: 입원 실질**
- 입력: { 쟁점:"입원 실질" }
- 출력: 필요서류=[입원기록·경과기록·처치내역], 문안=관찰·처치의 의학적 필요성 기재 요청

**예제 2: 치료 필요성(도수치료)**
- 입력: { 쟁점:"치료 필요성" }
- 출력: 필요서류=[치료기록지·통증·기능 평가·경과], 문안=치료 목적·반응 경과 구체 기재 요청
