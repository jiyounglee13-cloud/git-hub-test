---
name: clause-precedent-retriever
description: |
  시술·거절사유·세대를 입력받아 적용 약관 조항, 판례, 금융분쟁조정례를 매칭해
  유·불리 논점을 반환한다. 사용 시점: 다툼가능 판정 후 근거 정리(clause-precedent-analyst).
---

### 기능 설명
세대별 약관 면책/보장 조항 + 관련 판례·조정례 요지 + 일반 법리(작성자 불이익 원칙 등) 매칭.

### 입력 형식
{ 시술:"백내장", 거절사유:"입원 불인정", 세대:"3세대" }

### 출력 형식
{ 약관포인트, 유리근거[요지], 불리근거[요지], 반박논점후보 }

### 사용 예제
**예제 1: 백내장 입원 거절**
- 입력: { 시술:"백내장", 거절사유:"입원 불인정" }
- 출력: 입원 실질(관찰·처치 기록)로 다툼 가능, 입원 여부는 증상·진단·치료 종합 판단

**예제 2: 도수치료 횟수초과**
- 입력: { 시술:"도수치료", 거절사유:"횟수 초과" }
- 출력: 인과관계·치료효과 소명 시 조정 인정 사례 존재, 약관상 횟수 명시 여부 확인
