---
name: legitimacy-screening
description: |
  거절 사례를 '정당 면책 / 다툼가능 / 사기위험'으로 판정하고 근거와 다음 단계를 제시한다.
  거짓 희망 방지가 목적. 사용 시점: 반박 생성 직전(legitimacy-gate), 필수.
---

### 기능 설명
면책 사유(미용·임의비급여·횟수초과)·위험 정황·다툼 여지를 규칙 기반으로 선별.

### 입력 형식
{ 질환, 거절사유 패턴, 추가정황 }

### 출력 형식
{ 판정:[정당 면책|다툼가능|사기위험], 근거, 다음단계 }

### 사용 예제
**예제 1: 미용 목적 비밸브재건술**
- 입력: { 질환:"비밸브재건술", 거절사유:"미용 의심" }
- 출력: 판정=정당 면책, 다음단계=수용 안내

**예제 2: 의료자문 기반 도수치료 거절**
- 입력: { 질환:"도수치료", 거절사유:"의료자문상 불필요" }
- 출력: 판정=다툼가능, 다음단계=인과관계·치료효과 쟁점으로 진행
