# 카티스템 상담 올인원 (standalone)

상담 현장에서 쓰는 단일 파일 HTML 앱과, 환자 상담용 시각자료 모음입니다.
Next.js `public/` 아래에 있으므로 앱 구동 시 `/cartistem/consult.html` 로 바로 열립니다.

## 앱 구분 (탭) — 4개 → 5개

| 탭 | 설명 |
|----|------|
| 🩺 상담원 | 수술 전 일반 상담 카드 |
| 💬 상담실 FAQ | 환자 공유용 답변 |
| 🖼️ **환자자료 (신규)** | **의료진이 환자에게 보여주는 시각자료 모음** |
| 🔎 통합검색 | 전체 카드 검색 |
| 🛡️ 실손정보 | 실손보험 정보·거절 대응 |

## 환자 상담용 시각자료 (의료진용) — 3종

각 자료는 환자용 그림 + 접이식 **의료진 설명 포인트·주의(금지 표현)** 로 구성됩니다.
원본 제작자료(메디포스트 PDF) 슬라이드를 `img/` 에 함께 보관합니다.

1. `material-mechanism.html` — 카티스템® **작용 기전**
2. `material-production.html` — **GMP 생산 과정** & 발주·수술 일정
3. `material-cases.html` — **임상 사례** & 임상 3상 5년 추적 결과

## 컴플라이언스

모든 자료는 앱의 황금 규칙(효과·완치 단정 금지, 보험 보장 단정 금지, 경쟁치료 폄하 금지,
공포 조장 금지, 적응증 판단은 담당 의사)을 따릅니다.

> 내부 참고용입니다. 카티스템®은 전문의약품으로 치료 적합성·예후는 담당 의사가 판단합니다.
