# 실손 거절 대응 앱 — 규제·아키텍처 연구 (변호사법 리스크 헷지 중심)

> 이 문서는 사례집/대응 앱의 **법적 설계 근거**다. 핵심 결론: 우리 시스템은
> 규칙 기반 슬롯필링(rule-based slot-filling)이어야 하며, 생성형 AI의 법률 추론은
> 배제한다. 갱신 기준: 2026.6. 본 자료는 정보 제공용이며 법률 자문이 아니다.

## 1. 변호사법 리스크 — 가장 큰 상용화 장벽
- 비변호사가 영리 목적으로 타인의 법률사건 문서를 작성·대리하면 변호사법 위반.
- 손해사정사: 손해액·보험금 사정 업무만 가능. **보험금 청구 대리·이의신청서 작성 후
  수수료 수취는 변호사법 위반(징역·벌금)**. (법조신문, 로톡, 리걸타임즈)
- 따라서 본 앱은:
  - 성공보수·환수액 비율 수수료 모델 **금지**.
  - 사용자 **대리 제출 금지** → 완성 문서는 본인이 다운로드해 **본인 명의로 직접 제출(DIY)**.
  - 제휴 손해사정사의 유상 검수 결합 **금지**(법률사무 취급 소지).

## 2. 2026.2 대법원 '로폼(LawForm)' 판결 — 합법 슬롯필링의 기준
- 대법원 제3부: 내용증명·지급명령 등 **법률문서 자동작성 서비스는 변호사법 위반 아님**.
  (조선일보, 법률신문, 리걸타임즈)
- 합법 근거: 전문가가 사전 마련한 정형 서식에 사용자가 공란을 채우면(slot-filling)
  알고리즘이 **수정 없이 그대로** 문서화하는 구조 → 단순 작업 보조 도구.
- **경고(중요)**: 생성형 AI로 사용자의 자유 입력을 바탕으로 알고리즘이 **맥락을 자의적으로
  판단해 법률문서를 창작**하면 '법률사무 취급'에 해당할 소지 큼. 자동 생성 문서를
  제휴 비변호사가 유상 검토하는 것도 위법 소지.

### 규제 적합성 설계 매트릭스
| 서비스 요소 | 2026 대법원 기준 | 본 앱 적용 |
|---|---|---|
| 객관식 문진 기반 공란 채우기(slot-filling) | 적법 | ✅ 기본 UI 채택 |
| 생성형 AI 문맥 기반 문서 자율 창작 | 위법 리스크 높음 | ❌ 원칙적 배제 |
| 플랫폼이 사용자 명의 대행 제출 | 명백 위법 | ❌ 본인 직접 제출 |
| 자동 생성 문서를 제휴 손해사정사가 검수 | 명백 위법 | ❌ 알고리즘 산출물로 종료 |

> 함의: 우리 `/casebook`은 **규칙 기반 분기 + 빈칸 포함 초안 골격**만 제공하고 사용자가
> 직접 채워 본인 명의로 제출한다. 이는 로폼 기준의 '적법' 영역에 정확히 부합한다.
> 향후 B안(LLM 백엔드 자유생성)은 변호사법 위반 소지가 있어 채택하지 않는다.

## 3. 추가 통계 (앱 타깃·근거)
- 피해구제 신청자 연령: **40~60대 74.4%, 50대 29.1% 최다** → 중장년층이 정보비대칭 주피해자.
- 분쟁 다발 3종(백내장·도수·무릎줄기세포) 492건 중 **72.0%(354건)가 의원급**.
- 의료자문 결과 90%+ 소비자 불리, 이를 구실로 **평균 1,618만원** 고액 보험금 거부.
- 출처: 한국소비자원, 사건사고닷컴, 의협신문.

## 5. 인슈어테크 인프라 (향후 로드맵 — 현 정적 앱 범위 밖)
- **실손24(청구 전산화)**: 보험업법 개정으로 병·의원→보험사 전자전송 의무화. 30병상+ 시작,
  **2025.10 의원·약국 확대**. 제3자 청구·마이데이터 가족관계 확인, 네이버·토스 API 연계 예정.
- **마이데이터(신용정보원 크레딧포유) 연동**: 가입 세대(1~4세대)·특약·한도, 진료비 세부내역,
  KCD 질병분류기호 자동 수집 → 세대별 룰 자동 판별.
- **OCR/Vision AI**: 진단서·소견서에서 핵심 키워드(퇴행성 척추증, K-L 등급, VAS, ROM 수치)
  추출 → 객관식 검증("VAS 7→3 감소가 맞습니까?")으로 입력 최소화. (에임스 Autoclaim, 알체라)
- 주의: OCR/마이데이터는 자동화 '입력' 보조까지만. 법률 추론·창작은 여전히 배제(로폼 기준).
