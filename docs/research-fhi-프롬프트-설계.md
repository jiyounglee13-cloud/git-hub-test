# 한국형 'Fight Health Insurance' 도입을 위한 실손보험 이의신청 AI 프롬프트 설계 및 법률·데이터 연계 최적화 연구

> **갱신 기준**: 2026.6 · **면책 고지**: 본 자료는 정보 제공용이며 법률·보험 자문이 아니다.
> 이 문서는 `src/lib/casebook-data.ts` 및 `src/lib/prompt-architecture.ts` 설계 근거다.

---

## 서론: 정보 비대칭성 해소와 비영리 리걸테크의 시대적 요구

미국의 소프트웨어 엔지니어 홀든 카라우(Holden Karau)가 개발한 'Fight Health Insurance(FHI)'는 의료보험 청구 거절에 직면한 환자들을 위해 거대 언어 모델(LLM)을 활용하여 무료로 이의신청서를 작성해 주는 오픈소스 플랫폼이다. FHI 시스템은 개인정보 보호를 위해 클라이언트 기기 단에서 WebGPU 가속을 통한 OCR을 수행하며, 캘리포니아주 등의 공개된 이의신청 결정문을 역설계하여 생성한 합성 데이터를 바탕으로 Falcon 7B, MedGemma 등의 오픈소스 모델을 LoRA 기법으로 미세조정하여 구동된다.

한국의 의료보험 생태계 역시 미국의 상황과 본질적으로 유사한 정보 비대칭성의 모순을 안고 있다. 전 국민의 약 75%인 4,000만 명 이상이 가입한 실손의료보험을 둘러싼 분쟁은 매년 폭발적으로 증가하는 추세이다.

## 1. 실손보험 부지급 쟁점 분석 및 데이터베이스 구조화

### 1.1 분쟁 통계 분석

| 지표 | 통계치 | AI 프롬프트 설계 반영 |
|---|---|---|
| 소비자원 피해구제 사유 | 치료 필요 불인정 44.6%, 입원 필요 불인정 22.7% | 주치의 진단서·생체징후 데이터 요구 로직 필수 |
| 금감원 분쟁조정 인용률 | 2023상 18.3% → 2025상 40.3% | 금감원 신청 서식 최적화 템플릿 제공 |
| 보험사 소송 승소율 | 삼성화재 전부승소 98.5% | 소송 전 이의신청·분쟁조정 단계 집중 |

### 1.2 3대 분쟁 항목별 거절 논리와 판례 매핑

#### 백내장 다초점렌즈
- **보험사 논리**: 시력교정 목적·외모개선, 6시간 실질 관찰 불요 → 통원 한도 적용
- **대법원 원칙**: 일률적 입원 배제, 실질적 입원 필요성 심사 기준 (2024다305643, 2025.1.23.)
- **예외 인정**: 홍채섬모체염 기저질환 + 의사의 개별적 입원 지시 → 광주지법 항소심 입원 인정(630만원)
- **프롬프트 추출 대상**: 기저질환, 세극등 현미경 검사 결과, 주치의 개별 입원 지시 사유

#### 도수치료
- **보험사 논리**: 치료효과 미검증, 적정 횟수 초과, 과잉진료
- **판례 기조**: 1~3세대 약관에는 횟수 제한·매회 효과 확인 조항 미명시 → 작성자 불이익 원칙 적용 (전주지법 2022나23007, 대법 확정)
- **인정 요건**: 경추간판장애 등 방사선학적 객관적 진단 + 치료 후 ROM·VAS 호전
- **핵심 원칙**: 환자를 직접 대면하지 않은 보험사의 사후적 서면 의료자문으로 과잉진료 단정 불가
- **프롬프트 추출 대상**: 약관 횟수 제한 조항 존재 여부(세대별), VAS·ROM 변화 기록

#### 무릎 줄기세포 주사(BMAC)
- **핵심 쟁점**: 시술 후 입원 관찰의 의학적 필요성
- **서울중앙지법 2024가단55065**: 9명 중 2명만 입원 인정
  - **기각(7명)**: '증세 악화 우려' 복사 문구, 단순 체류 시간만으로 불인정
  - **인정(2명)**: 고혈압+아스피린 장기복용 출혈위험 / 시술 후 혈압 162/100mmHg 급상승
- **프롬프트 추출 대상**: 간호기록지의 생체징후(혈압·맥박) 변화 데이터, 기저질환·상용약물 기록

### 1.3 가드레일: 승소 불가능 사안 배제 논리

대법원 판례로 보험사 면책이 확정된 사안은 작성 거절 후 법률적 이유를 고지한다.

| 배제 사유 | 근거 판례 | 안내 메시지 |
|---|---|---|
| 지인·직원 할인 감면액 청구 | 대법원 2024.10.31. 2023다240916 | 실제 부담액만 담보, 감면분은 실손 대상 외 |
| 본인부담상한제 사후환급금 | 대법원 2024.1.25. 2023다283913 | 공단이 최종 부담한 비용, 이득금지 원칙 |
| 위험분담제 제약사 환급금 | 이득금지 원칙 | 최종 환자 손해 아님 |

## 2. 의료자문(Medical Advisory) 강요 대응 로직

- **의료자문 동의는 법적 의무 아님** — 거부 가능
- 보험사 자문 결과의 90%+ 가 소비자에게 불리하게 도출됨
- **거절 통지서에서 '의료자문' 키워드 감지 시 자동 방어 로직 가동**:
  1. "환자를 직접 대면하지 않은 서면 심사는 주치의 임상 소견을 우선할 수 없다" 명시
  2. 분쟁 지속 시 보험사·계약자 합의 제3 대학병원 **동시감정(Simultaneous Appraisal)** 공식 요청 문구 삽입
  3. 동시감정 비용은 약관(제19조)상 보험사 전액 부담 명시

## 3. 리걸테크 규제 환경과 변호사법 위반 회피

### 3.1 대법원 로폼 판결 (2025두35483, 2026.2.12.)

- **합법 영역**: 전문가 사전 마련 정형 서식에 사용자가 공란을 채우면 알고리즘이 수정 없이 문서화 → 단순 작업 보조 도구 (변호사법 위반 아님)
- **위법 경고**: 생성형 AI가 사용자의 자유 입력을 바탕으로 맥락을 자의적으로 판단해 법률문서를 창작하면 '법률사무 취급'에 해당

### 3.2 규제 순응형 설계 원칙

| 서비스 요소 | 기준 | 본 앱 |
|---|---|---|
| 객관식 문진 기반 공란 채우기(slot-filling) | 적법 | ✅ |
| 생성형 AI 맥락 기반 문서 자율 창작 | 위법 리스크 | ❌ |
| 플랫폼이 사용자 명의 대행 제출 | 명백 위법 | ❌ |
| 성공보수·수수료 수취 | 변호사법 위반 | ❌ |

## 4. 3단계 프롬프트 아키텍처 설계

### 4.1 시스템 롤 플레잉 및 경계 설정 (Meta & System Prompt)

```
당신은 한국의 실손의료보험 가입자가 정당한 치료 후 보험금 지급을 거절당했을 때,
사용자가 제공한 사실관계와 거절 통지서 내용을 바탕으로 이의신청서 초안 구성을
돕는 비영리 '의료·행정 문서 서식 작성 보조 도구'입니다.

[엄격한 제약 사항 - 변호사법 제109조 및 의료법 준수]
- 자아 인식: 변호사, 손해사정사, 또는 전문 의료인이 아닙니다.
- 독자적인 법적 판단, 승소 확률 예측, 의학적 진단을 내리는 행위 절대 금지.
- RAG 파이프라인으로 주입된 판례·분쟁조정례를 서식에 재배열·병합하는 역할만 수행.
- RAG에 없는 허구의 판례·약관·법리를 창작(Hallucination) 절대 금지.

[배제 대상 필터링]
- "지인 할인", "병원 직원 할인", "본인부담상한제 사후환급금" 키워드 감지 시:
  대법원 판례(2023다240916, 2023다283913)에 의거 이의신청서 작성 중단 후 안내.

[작성 스타일]
- 사견 배제 건조하고 객관적인 공문서 어조
- 서식: [문서 번호/제목] - [청구 개요 및 경과] - [부지급 처분의 부당성 및 관련 근거] -
  [향후 조치 및 요구사항] 4단 구조 엄수
```

### 4.2 맥락 주입 및 RAG 연동 블록 (Context Injection)

사용자가 업로드한 문서의 OCR 추출 텍스트와 벡터 데이터베이스(Cosine Similarity 기준)에서
검색된 판례를 결합하여 모델에 주입한다.

예시 (BMAC 입원 불인정 사례):
```
[RAG 검색 추출 지식 기반 - 서울중앙지방법원 2024가단55065]
핵심 판시: 입원의 실질적 필요성은 단순 체류 시간이 아닌 의료적 필요성으로 판단.
천편일률적 증세 악화 우려는 불인정. 단, 기저질환(고혈압·아스피린 복용)과
시술 직후 생체징후 변화(혈압 162/100mmHg 상승)가 의무기록으로 객관적으로 입증된 경우,
의료진의 지속적 관찰 필요성이 합법적으로 인정됨.
```

### 4.3 작업 지시 및 연쇄적 사고 유도 (Chain-of-Thought Task Instruction)

```
Step 1 (논리 매핑): 사용자 상황(기저질환·생체징후)과 보험사 거절 논리(입원 불인정)가
  RAG 제공 판례와 어떻게 부합하는지 내부적으로 교차 검증.

Step 2 (초안 병합): 교차 검증 완료 후, 사실관계 데이터를 표준 서식 빈칸에 매핑.
  주치의의 임상적 판단 우선을 부각.
  거절 사유에 '의료자문'이 있으면 동시감정 요청 문구 반드시 추가.

Step 3 (안전장치 추가): 최종 문서 하단에 다음 면책 고지 삽입:
  "본 문서는 사용자의 입력을 바탕으로 공인된 판례 데이터를 기계적으로 매핑하여 생성된
  서식 초안일 뿐, 법률적 또는 의학적 자문이 아닙니다. 제출 전 본인의 의무기록과
  사실관계가 일치하는지 반드시 직접 확인하시기 바랍니다."
```

## 5. 기술적 신뢰성 확보

### 5.1 도메인 특화 미세조정 (Fine-tuning)

한국 보험 실무 용어의 정확한 이해를 위해 FHI 방법론과 동일하게:
- 금융감독원 분쟁조정 결정문, 한국소비자원 피해구제 사례, 대법원 판결문 PDF 크롤링
- PII 익명화(Scrubbing) 처리
- "질병명 - 거절 사유 - 판례 인용 - 반박 논리" 구조의 합성 훈련 데이터 수만 건 생성
- 한국어 LLM을 LoRA 기법으로 파인튜닝

### 5.2 실손24 및 마이데이터 API 연계

- 2024년 말: 보험개발원 '실손24' 앱 — 진료비 영수증·세부내역서·처방전 전자 전송
- 2025년 11월: 실손24 ↔ 네이버·토스 등 민간 플랫폼 마이데이터 API 연동 (병원 예약→청구 일원화)
- **활용 방안**: 마이데이터 동의 후 실손24 API 호출 → 지급 거절(면책) 처리된 청구 건의
  정형 데이터(병원명, 진료일자, KCD 코드, 청구 의료비 상세 내역)를 JSON으로 자동 주입
  → OCR 인식 오류·수기 입력 실수 원천 차단

## 6. 결론 및 향후 로드맵

본 연구는 다음을 확인하였다:

1. **3대 분쟁 항목 판례 매핑**: 백내장(기저질환+개별입원지시), 도수치료(약관 명시성+VAS·ROM),
   BMAC(생체징후 변화)에 대한 RAG 지식 베이스 구축이 핵심.

2. **의료자문 방어 로직**: 거절 통지서에서 '의료자문' 키워드 감지 시 동시감정 요청 자동 삽입.

3. **변호사법 가드레일**: 대법원 로폼 판결 기준의 규칙 기반 슬롯필링 구조 유지.
   AI가 독립적 법률 자문자로 작동하는 것을 원천 차단.

4. **지속적 업데이트 파이프라인**: 금감원 분쟁조정 기준과 하급심 판례의 RAG 데이터베이스 실시간 갱신.
