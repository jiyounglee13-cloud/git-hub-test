# 무릎 OA & HTO 보조 도구 — 임상 검증 로드맵

> 본 문서는 `/xray` 데모(연구·교육용)를 임상 활용 가능한 수준으로 끌어올리기 위한
> 단계별 계획을 정리한다. **현재 산출물은 데모이며 진단·치료 목적으로 사용할 수 없다.**

## 1. 현재 상태 (Phase 0 · 데모)

| 영역 | 구현 | 한계 |
|---|---|---|
| K&L 판독 | Claude 비전 추론(`temperature 0` + 다중표본 다수결), 영상 적합성 평가 | 재현성·정확도 미검증, 학습 데이터 없음 |
| 정렬 계측 | WBL%, HKA, MPTA(전/후), JLCA, mLDFA — 결정론적 기하(`src/lib/hto.ts`) | 사용자 랜드마크 정확도에 종속, 단일 영상 |
| HTO 계획 | Miniaci 변형 교정각·개대 쐐기, Before/After 시뮬레이션, 시나리오 | 기하 시뮬레이션(수술 결과 예측 아님) |
| 안전장치 | MPTA>95°, 교정각>12°, JLCA>4°, mLDFA 이상, K&L4 금기 경고 | 규칙 임계값은 문헌 기반 근사 |

### 핵심 설계 — 백엔드 교체 지점
판독 엔진은 `KLGrader` 인터페이스(`src/lib/grader.ts`) 뒤에 있다. 임상화 시
**LLM 백엔드 → 전용 CNN 백엔드** 로 교체하되 API·UI는 수정하지 않는다.

```
getGrader()  ← KL_BACKEND
  ├─ LLMGrader  (Phase 0, 데모)
  └─ CNNGrader  (Phase 2, 임상)  ← 이 클래스만 구현하면 교체 완료
```

## 2. 단계별 로드맵

### Phase 0 — 데모 (현재)
- 목적: 워크플로우·UX 시연, 이해관계자 피드백 수집.
- 산출물: 본 저장소의 `/xray`.
- 비목표: 정확도 주장, 환자 데이터 사용.

### Phase 1 — 후향적 검증 (3~6개월)
1. **데이터 확보**
   - 공개: OAI(Osteoarthritis Initiative), MOST — K&L 라벨 보유.
   - 자체: 기관 IRB 승인 후 후향적 무릎/전장하지 기립영상 수집(DICOM 원본).
2. **라벨링**
   - K&L: **3인 이상 판독자 합의(또는 다수결) 라벨** — 단일 판독자 라벨 금지.
   - 정렬 각도: 숙련 정형외과의 수기 계측을 ground truth로.
3. **모델 개발**
   - 2단계: ① 무릎 관절부 검출/crop → ② 등급 분류.
   - 다시점(AP+lateral) + 관절 영역 분할 사전지식, 골극·JSN 멀티태스크.
   - 자체 데이터로 fine-tuning + **외부(타기관) 검증**으로 도메인 시프트 점검.
4. **랜드마크 자동검출**: 전장하지 기립영상에서 hip/knee/ankle/관절선 자동 검출 모델.

### Phase 2 — 임상 통합 (6개월~)
- 전향적 검증, PACS/DICOM 통합, `CNNGrader` 구현으로 백엔드 교체.
- 사용성·임상 유효성 평가, 의료기기 인허가(아래 6장).

## 3. 검증 지표 (수용 기준 예시)

### K&L 등급 분류
- **Balanced accuracy**, **Cohen's quadratic-weighted κ**(판독자 간 일치 반영), **macro-AUC**.
- 인접 등급(1↔2, 2↔3) 경계 오류율 별도 보고(K&L의 본질적 관찰자 간 변동성).
- 목표: κ ≥ 0.7(상당) 이상, 등급별 민감도/특이도 공개.

### 정렬·HTO 계측
- 자동 vs 전문의 수기 계측의 **각도 RMSE / 절대편차 / Bland-Altman LoA**.
- HKA·mTFA는 전체 정렬에서 RMSE ~1° 수준 달성 가능하나, **관절 단위 각도(MPTA/mLDFA)는 편차가 크므로** 별도 임계 관리.
- 교정각·쐐기 높이의 **재현성(반복 측정/판독자 간)**.

## 4. 현재 데모의 알려진 한계
1. **재현성**: LLM 등급은 동일 영상도 호출 간 변동 가능(데모는 `temperature 0`로 완화, 다중표본 일치율 표기).
2. **영상 의존**: 화면 캡처·8bit JPEG는 정밀 계측 부적합 → DICOM 원본·픽셀-mm 캘리브레이션 필요.
3. **단일 정면 영상**: HTO 정밀 계획은 전장하지 기립영상 필수. 후방 경사는 측면상에서만 측정.
4. **연골 평가 불가**: X-ray로 직접 평가 불가(MRI/관절경 필요) — 시나리오는 의사 입력 전제.
5. **쐐기 높이 근사**: 절골선 길이를 평탄부 기하로 근사 — 실제 절골 레벨/경사와 차이.
6. **거짓 정밀도 방지**: 각도 0.5°·쐐기 0.5mm 반올림으로 표기.

## 5. 위험 및 안전
- 자동 산출값의 **과신 방지**: 모든 결과에 신뢰도·한계·"보조도구" 표기.
- **포지셔닝**: AI 자동 진단이 아닌 *의사 판단을 돕는 계산·보조 도구*.
- 안전 경고(과교정·경첩 골절·변형 기원 부위·금기)를 전면 노출.

## 6. 규제 고려
- 진단·수술계획 산출 소프트웨어는 대체로 **의료기기(SaMD)** 에 해당.
  - 국내: **식약처(MFDS)** 인공지능 의료기기 가이드라인.
  - 미국: **FDA** (SaMD, Predetermined Change Control Plan, GMLP).
- 학습/검증 데이터 거버넌스, 설명가능성, 변경관리, 시판 후 감시(PMS) 체계 필요.
- **데모(연구용)와 진료용 사이의 선을 명확히** 유지 — 본 저장소는 연구·교육용.
