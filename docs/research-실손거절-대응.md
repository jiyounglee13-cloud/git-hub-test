# 실손보험 지급 거절 실태 및 단계별 대응 — 연구 요약 (사례집 시스템 근거 자료)

> 이 문서는 `src/lib/casebook-data.ts` 룰의 사실 근거다. 통계·판례·제도는 변동되므로
> 갱신 시점을 함께 기록한다. 본 자료는 정보 제공용이며 법률·보험 자문이 아니다.
> 갱신 기준: 2024~2025년 자료(한국소비자원·금융감독원·대법원 판례).

## 1. 거절 사유 통계 (한국소비자원, 2021.1~2024.9, n=1,016)
| 사유 유형 | 비중 | 핵심 맥락 |
|---|---|---|
| 치료 필요 불인정 | 44.6% | 객관적 검사 부재, 유지목적 과잉진료 의심, 신의료기술 요건 미달 |
| 입원 필요 불인정 | 22.7% | 6시간 형식요건만으로 불인정, 지속적 관찰 필요성 미입증 |
| 본인부담상한액 환급금 불인정 | 10.3% | 공단 사후환급분 사전 공제·부지급 |
| 기타(고지의무 위반, 면책조항 확대해석 등) | 22.4% | — |

- 피해구제 신청의 72.0%가 의원급 의료기관 사건. 거절의 67.4%가 주치의 진단 불인정 관련.
- 출처: 한국소비자원 보도자료, 뉴시스.

## 2. 의료자문 방어 (1단계 핵심)
- 의료자문 동의는 **법적 의무가 아닌 협조 요청**. 거부 가능.
- 자문 결과의 90%+가 보험사 의도대로 '인과관계/필요성 없음' 도출 → 거절 명분.
- 대안: **동시감정** — 보험사·계약자가 합의해 중립 대학병원 전문의를 공동 선정.
  관련 약관(제19조 의료자문 결과 피해구제절차)상 **동시감정 비용은 보험사 전액 부담**.
- 출처: 사건사고닷컴, 손해보험협회 소비자포털.

## 3. 입증 서류 (2단계 재청구)
- 진단서 한 장 불충분. 초진·경과·투약·간호기록지, 입퇴원요약지, 검사결과지(X-ray·MRI 판독지) 일체.
- 주치의 '상세 소견서'로 거절 사유 정면 반박. 2025년 '표준 의학 소견서' 양식 도입.
- 고지의무: 2025 개정 보험업법상 **서면 질문 사항에 한해** 고지의무 성립.
  가입 후 **3년 경과 시** 고지의무 위반 이유 해지·부지급 원칙적 불가(상법).

## 4. 분쟁조정·소송 인용률
| 구제 단계 | 인용/승소율 | 비고 |
|---|---|---|
| 한국소비자원 합의율(손보 8개사 평균) | 28.3% | 난건만 모이는 후단 사례 → 통계적 착시 |
| 금감원 제3보험(실손) 인용률 2023상 | 18.3% | |
| 금감원 제3보험 인용률 2024상 | 26.9% | |
| **금감원 제3보험 인용률 2025상** | **40.3%** | 비급여 가이드라인 확립, 집중처리 |
| 민사소송 소비자 승소율(생보, 2019~2023) | 매년 17% 미만 | 보험사 체리피킹 |
| 민사소송 보험사 평균 승소율(손보) | 79.2% | 삼성화재 전부승소 98.5% |

- 금감원 분쟁조정 수락 시 **재판상 화해**와 동일 효력. 신청만으로 **소멸시효 중단**.
  자율조정 ~30일, 위원회 회부 후 60일 내 조정안.
- 출처: 금감원 보도자료, 국정감사 자료, KIRI, 손해보험협회.

## 5. 심사기준 변경 사전안내 (2024.5~ 실손 우선)
- 대법원 판례·당국 유권해석 근거로 심사기준을 소비자 불리하게 변경 시,
  **적용 3영업일 전**까지 2개 이상 채널(알림톡·앱 푸시)로 개별 안내 + 홈페이지 공시.
- 심사부서 단독 변경 금지, 법무·소보 임원 참여 내부통제 심의 강제.

## 6. 주요 판례 (사례집 룰 근거)
### 6.1 도수치료 — 약관 명시성 + 주치의 임상소견 우위
- 전주지법 2022나23007(대법 확정): 1년간 100회+ 도수치료, 1~2세대 약관에
  도수치료 횟수 제한·매회 효과확인 조항 **없음** → 작성자 불이익 원칙 → 전액(3,103,300원) 인정.
- 승소 요건: 치료 전후 **통증척도(VAS)·관절가동범위(ROM)** 변화 입증.
- 단, **4세대(2021.7~)는 3대 비급여 특약으로 연 50회 제한 + 10회 단위 호전 확인** → 위 판례 부적용.

### 6.2 입원의 실질적 필요성 (백내장·무릎 줄기세포 BMAC)
- 6시간 체류 형식요건만으로 입원 불인정. '지속적 관찰 요보호 상태' 입증 필요.
- 백내장: 대법원 2022·2023 — 원칙적 통원(통원한도 약 25만원). 단 광주지법 항소심 —
  '홍채섬모체염' 기저질환 입증 → 합병증 방지 목적 입원 인정, 630만원 지급.
- BMAC: 서울중앙지법 2024가단55065 — 9명 중 2명만 입원 인정.
  - 기각(7명): 진료기록에 '증세 악화 우려' 복사 문구 반복, 시술 1시간 내외·사후처치 없음.
  - 인정(2명): 고혈압·아스피린 장기복용으로 출혈위험 관찰 필요 기재 / 시술 후 혈압 162/100
    급상승 등 **생체징후(Vital sign) 변화** 입증.
- 승패 요인: 혈압 급상승·약물 복용력·통증척도 등을 기록한 **간호기록지** 등 구체적 의료기록.

### 6.3 이득금지의 원칙 (작성자 불이익 원칙이 깨지는 영역)
- 본인부담상한제 환급금: 대법원 2024.1.25. 2023다283913 — **1~4세대 불문** 보상 대상 아님.
- 지인할인·임의 감면액: 대법원 2024.10.31. 2023다240916 — 실제 부담액만 담보, 감면분 부지급.
- 제약사 위험분담제 환급금: 최종 환자 손해 아님 → 부지급.
- 함의: 약관 모호성(작성자 불이익) 주장이 손해보험 대원칙(이득금지·실손보상) 앞에선 불수용.
  → 이 항목들은 분쟁 전 스스로 공제해 기대치 조정.

## 7. 소송비용 패소자 부담 (민사소송법 제98조)
변호사보수 산입 상한(소가 기준):
| 소가 | 상한액 |
|---|---|
| 300만원 이하 | 30만원 |
| 300만~2,000만원 | 30만원 + (소가-300만)×10% |
| 2,000만~5,000만원 | 200만원 + (소가-2,000만)×8% |
| 5,000만~1억원 | 440만원 + (소가-5,000만)×6% |
| 1억~1.5억원 | 740만원 + (소가-1억)×4% |
- 패소 시 상대방 인지대·송달료·감정료·변호사보수(상한 내)까지 부담. 심급마다 누적.
- 진료기록감정료 약 50만~100만원 신청자 예납.

## 8. 시술별 적응증 가이드 (참고)
- BMAC(무릎 줄기세포 주사): 신의료기술 고시상 K-L 등급 **2~3등급** 대상.
  2등급 미만 경미/4등급(연골 50%+ 손상)은 거절 빈발. ※ 카티스템(2012 허가 전문의약품·수술)과 별개.
- 체외충격파(도수치료 풍선효과): 금감원 가이드라인 — 7개 관절(어깨·팔꿈치·고관절·슬관절·
  발목·족저근막·척추), **연 최대 12회, 부위당 최대 6회**.
